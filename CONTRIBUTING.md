# Contributing

Este repositório é um projeto de estudo pessoal.

Enquanto o código ainda não existe, o fluxo esperado é:

1. implementar uma fatia pequena (por exemplo configuração, um módulo ou um teste);
2. manter a lógica no lugar previsto pela estrutura (`api/`, `services/`, `repositories/`, `ai/`, `tests/`);
3. não antecipar features fora do escopo da etapa atual.

Quando houver código, detalhes de estilo, testes e ambiente local serão documentados aqui.
