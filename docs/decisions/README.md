# Architecture Decision Records (ADRs)

Esta pasta guarda decisões de arquitetura no formato ADR.

Cada ADR deve registrar um problema, as opções consideradas e a decisão tomada. Não crie ADRs antecipando tecnologias ou abordagens que ainda serão estudadas.
